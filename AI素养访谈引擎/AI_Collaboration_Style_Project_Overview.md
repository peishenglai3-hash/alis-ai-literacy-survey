# AI协作风格访谈引擎 - 项目总览

## 📋 项目概述

这是一个用于社会学田野调查的AI素养访谈引擎，围绕"AI协作风格"这一创新概念，将传统的AI素养量表转化为交互式、情境化的访谈产品。

### 核心创新点
1. **从测量到测试**：不只给出分数，更判定协作风格类型
2. **从静态到动态**：量表转化为"叙事触发器"
3. **从黑箱到透明**：暴露评价过程，让分类本身成为讨论对象
4. **从单向到双向**：系统主导访谈，人类促进对话

## 🎯 核心设计理念

### 1. 四个核心维度
```
Dimension 1: AI Orientation（AI接近方式）
- Explorer（探索者） vs Navigator（导航者）

Dimension 2: AI Trust（AI信任模式）
- Verifier（验证者） vs Collaborator（协作者）

Dimension 3: AI Relationship（AI关系模式）
- Instrumental（工具型） vs Integrated（融合型）

Dimension 4: AI Responsibility（责任模式）
- Self-focused（自我优化） vs Social-aware（社会反思）
```

### 2. 八种协作风格
1. **AI探索者** - 🔍 好奇驱动，主动尝试
2. **AI实践家** - ⚡ 效率导向，任务明确
3. **AI验证者** - 🔬 批判思维，主动验证
4. **AI协作者** - 🤝 互动共创，持续调整
5. **AI依赖型使用者** - 🔌 高频使用，深度依赖
6. **AI观察者** - 👁️ 保持距离，谨慎思考
7. **AI反思者** - 🤔 社会关注，价值思考
8. **AI平衡者** - ⚖️ 协调各方，灵活应对

### 3. 访谈流程设计
```
Step 1: 量表填写
    ↓
Step 2: 维度评分（4个维度的得分和倾向）
    ↓
Step 3: 风格判定（8种协作风格之一）
    ↓
Step 4: 画像呈现（描述、优势、盲区、反思问题）
    ↓
Step 5: 共同回味（逐题暴露评价过程）
    ↓
Step 6: 追问对话（基于Follow-up Graph的动态追问）
    ↓
Step 7: 深度反思（对AI素养概念的重新思考）
```

## 🔧 技术架构概览

### 前端技术栈
```
Vue.js 3.0 (Composition API)
├── Element Plus (UI组件)
├── Pinia (状态管理)
├── Vue Router (路由)
└── Axios (HTTP客户端)
```

### 后端技术栈
```
FastAPI (Python 3.10+)
├── SQLAlchemy (ORM)
├── SQLite (数据库)
├── WebSocket (实时通信)
└── Pydantic (数据验证)
```

### 核心模块
```
1. 问卷模块 - 题目展示和答案收集
2. 评分模块 - 维度计算和风格判定
3. 画像模块 - 个性化反馈生成
4. 追问模块 - 动态对话系统
5. 访谈模块 - 会话管理和记录
```
