# AI协作风格量表映射关系

## 设计理念：从"风格类型"到"认知旅程框架"

本文档不仅提供题目到维度的技术映射关系，更重要的是为**6阶段认知旅程**提供结构化导航。

**核心理念转变**：
- **旧**：15道题作为分类数据源 → 生成风格类型 → 访谈终点
- **新**：15道题作为认知旅程路标 → 建立风格框架 → 重新经历6个认知阶段 → 旅程回望 → AI素养重构

**15道题的6阶段认知旅程**：
```
第一阶段：认识AI (Q1, Q2)
    ↓
第二阶段：使用AI (Q3, Q4, Q5, Q6)
    ↓
第三阶段：信任AI (Q7, Q8, Q9, Q12)
    ↓
第四阶段：与AI相处 (Q10, Q11, Q14)
    ↓
第五阶段：理解AI (Q10, Q11 - 跨阶段重复)
    ↓
第六阶段：重新定义AI (Q14, Q15 - 跨阶段重复)
```

## 三、评分计算逻辑

### Step 1: 计算每个维度的得分

```python
# Dimension 1: AI Orientation
orientation_score = (Q1 + Q2 + Q3 + Q4 + Q5 + Q6) / 6

# Dimension 2: AI Trust
trust_score = (Q5 + Q7 + Q8 + Q9 + Q12) / 5

# Dimension 3: AI Relationship
relationship_score = (Q2 + Q3 + Q9 + Q10 + Q11 + Q14) / 6

# Dimension 4: AI Responsibility
responsibility_score = (Q10 + Q11 + Q12 + Q13 + Q15) / 5
```

### Step 2: 判定每个维度的倾向

```python
def determine_tendency(score):
    if score >= 5.5:
        return "strong_A"  # 强A端倾向
    elif score >= 4.5:
        return "moderate_A"  # 中等A端倾向
    elif score >= 3.5:
        return "neutral"  # 中立
    elif score >= 2.5:
        return "moderate_B"  # 中等B端倾向
    else:
        return "strong_B"  # 强B端倾向
```

### Step 3: 基于维度组合判定协作风格

```python
def determine_collaboration_style(orientation, trust, relationship, responsibility):
    # 逻辑树判定
    if orientation["type"] == "Explorer" and trust["type"] == "Collaborator":
        return "AI探索者"
    elif orientation["type"] == "Navigator" and relationship["type"] == "Instrumental":
        return "AI实践家"
    elif trust["type"] == "Verifier":
        return "AI验证者"
    elif trust["type"] == "Collaborator" and relationship["type"] == "Integrated":
        return "AI协作者"
    elif trust["score"] >= 6 and relationship["score"] >= 6:
        return "AI依赖型使用者"
    elif orientation["score"] <= 4 and responsibility["type"] == "Social-aware":
        return "AI观察者"
    elif responsibility["type"] == "Social-aware":
        return "AI反思者"
    else:
        return "AI平衡者"
```

## 四、需要注意的设计原则

### 原则1: 不是"高低"，而是"倾向"
- 不应该说"高分优于低分"
- 每种类型都有优势和盲区
- 类型是描述性的，不是评价性的

### 原则2: 不是"固定人格"，而是"当前状态"
- 类型会变化
- 强调"当前协作风格"
- 鼓励反思和调整

### 原则3: 类型是"互动对象"，不是"标签"
- 类型是为了引发讨论
- 鼓励受访者质疑、修改、重新定义
- 类型本身是研究对象

### 原则4: 保持学术严谨性
- 维度完全来自权威量表（MAILS、清华、SNAIL）
- 类型判定基于组合逻辑，不是简单总分
- 每种类型都有明确的理论依据
