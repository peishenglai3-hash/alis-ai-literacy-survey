# 界面交互原型设计

## 设计理念转变

**从**：风格类型作为访谈终点（"我是如何与AI交互的"）
**到**：风格类型作为认知旅程入口（"带着风格框架重新经历15题的叙事路径"）

**核心交互转变**：
- 旧版：风格画像 → 开放对话 → 概念探讨 → 结束
- 新版：风格框架呈现 → 结构化认知旅程（6阶段） → 旅程回望 → AI素养重构

## 交互流程的关键设计决策（更新版）

### 决策1：如何从风格框架过渡到认知旅程？

**解决方案：使用"框架-旅程-回望"三层结构**

```
Layer 0: 框架建立
系统："这不仅是测试结果，而是理解你AI使用方式的认知框架"

Layer 1: 结构化旅程
系统："接下来，我们将用这个框架重新经历6个认知阶段"

Layer 2: 旅程回望
系统："通过这段旅程，我们发现你的'AI协作者'风格不只是使用习惯，
      而是一套完整的认知框架"
```

### 决策2：如何让每道题都成为深度追问的起点？

**解决方案：题目特定追问序列（Question-Specific Follow-up Sequence）**

```
对于每道题，根据用户的回答（1-7分）+ 风格框架，生成个性化追问：

1. 经验唤起
   "你在Q7中选择了'非常同意'，能具体讲一个你验证AI的例子吗？"

2. 框架连接
   "作为'AI协作者'，你什么时候会验证，什么时候不会？"

3. 跨题矛盾检测
   "你在Q5表示'经常与AI协作'，但在Q8表示'有时会验证'，
   这两种行为之间的张力你是如何处理的？"

4. AI素养桥接
   "这种选择性验证的做法，其实是AI素养研究中'信任判断'的核心"

5. 反思深化
   "这段旅程让你对自己的信任判断有什么新的理解？"
```

### 决策3：如何处理跨越多个阶段的题目（Q10, Q11, Q14）？

**解决方案：跨阶段重复 + 不同视角对比**

```
Q10的处理方式：

第四阶段（与AI相处）：
"AI如何影响你的日常生活？"
→ 探讨个人层面影响

第五阶段（理解AI）：
"AI如何影响社会？"
→ 探讨社会层面影响

旅程回望时：
"对比你对Q10的两次回答，你发现了什么？"
→ 引导用户发现从个人到社会的认知扩展
```

### 决策4：如何让用户感知到"我在旅程中"？

**解决方案：三重可视化 + 阶段性过渡仪式**

```
可视化1：持久侧边栏
- 实时显示当前阶段
- 显示本阶段题目
- 累积显示阶段发现

可视化2：旅程进度条
- ▶▶▶▶▶░░（3/6阶段完成）
- 让用户明确感知进展

可视化3：阶段过渡仪式
- 每完成一个阶段，显示"阶段完成"界面
- 总结本阶段发现
- 预告下一阶段内容
- 明确告知旅程进展
```

### 决策5：如何避免显得像说教而保持对话感？

**解决方案：用户原话 + 框架持续性使用**

```
❌ 不好：
"AI素养包括认识AI、使用AI、信任AI等6个阶段，这很重要。"

✅ 好：
"通过你在Q7和Q8的回答，我发现你作为'AI协作者'已经形成了一套
选择性信任的机制。这其实是AI素养研究关注的核心：信任不是简单的
信/不信，而是基于情境的动态判断。"

关键要素：
1. 使用用户在具体题目中的回答
2. 持续引用"AI协作者"框架
3. 用"AI素养研究"而非"你应该"
4. 保持探讨而非教育的语气
```

## 界面交互流程总结

### 完整用户旅程
```
1. 测试完成
   ↓
2. 风格框架呈现（"这不仅是测试结果，而是认知框架"）
   ↓
3. 旅程说明（6个阶段预告）
   ↓
4. 认知旅程开始
   ├── Stage 1: 认识AI (Q1, Q2)
   │   └── 阶段过渡：总结发现 + 预告下一阶段
   ├── Stage 2: 使用AI (Q3, Q4, Q5, Q6)
   │   └── 阶段过渡：总结发现 + 预告下一阶段
   ├── Stage 3: 信任AI (Q7, Q8, Q9, Q12)
   │   └── 阶段过渡：总结发现 + 预告下一阶段
   ├── Stage 4: 与AI相处 (Q10, Q11, Q14)
   │   └── 阶段过渡：总结发现 + 预告下一阶段
   ├── Stage 5: 理解AI (Q10, Q11 跨阶段重复)
   │   └── 阶段过渡：总结发现 + 预告下一阶段
   └── Stage 6: 重新定义AI (Q14, Q15 跨阶段重复)
       └── 阶段过渡：总结发现 + 预告旅程回望
   ↓
5. 旅程回望
   ├── 6个阶段完成总结
   ├── 作为"AI协作者"的认知旅程特点
   └── 核心发现呈现
   ↓
6. AI素养概念重构
   ├── 传统AI素养测试 vs 认知框架视角
   └── 用户对新理解的回应
   ↓
7. 访谈结束
```

### 关键设计特点

1. **框架持续性**：用户风格框架贯穿整个旅程，作为理解透镜
2. **结构化自由**：6个阶段提供结构，但每个阶段内保持对话的开放性
3. **题目价值最大化**：每道题都成为深度追问的起点，15题都不浪费
4. **旅程可视化**：用户明确感知"我在哪里"、"要去哪里"
5. **阶段性过渡**：每个阶段完成后都有仪式感，强化旅程感
6. **跨阶段题目处理**：Q10、Q11、Q14在不同阶段以不同视角探讨
7. **回望与重构**：旅程完成后帮助用户重新理解AI素养概念

---

这个重构后的界面设计实现了从"风格类型作为访谈终点"到"风格类型作为认知旅程入口"的核心转变，通过6个阶段的结构化旅程，让用户的每次认真选择都成为深度反思的起点，最终实现AI素养概念的重新理解。
