# 认知旅程设计：从风格框架到AI素养重构

## 一、核心理念转变

### 1.1 从"风格类型作为终点"到"风格类型作为认知旅程入口"

**原有设计的问题**：
- 风格类型成了访谈的"最终结果"（"我是如何与AI交互的"）
- 15道题只是计算风格类型的数据来源
- 完成测试后，用户的每道题选择就失去了价值

**新的设计理念**：
- 风格类型是"认知框架"，而非"终点标签"
- 带着这个框架，重新审视15道题的选择
- 每道题都成为深度追问的起点

**用户旅程重构**：
```
旧：完成15题 → 得到风格类型 → 开放式对话 → 访谈结束
新：完成15题 → 建立风格框架 → 结构化认知旅程 → 旅程回望 → AI素养重构
```

### 1.2 15道题的隐性叙事路径

**这15道题不是随机排列**，而是一条认知发展的旅程：

```
认识AI → 使用AI → 信任AI → 与AI相处 → 理解AI → 重新定义AI
```

**具体对应**：
```
第一阶段：认识AI (Q1, Q2)
    ↓
第二阶段：使用AI (Q3, Q4, Q5, Q6)
    ↓
第三阶段：信任AI (Q7, Q8, Q9, Q12)
    ↓
第四阶段：与AI相处 (Q10, Q11, Q14)
    ↓
第五阶段：理解AI (Q10, Q11) - 跨阶段重复
    ↓
第六阶段：重新定义AI (Q14, Q15) - 跨阶段重复
```

**跨越性题目的处理**（用户确认）：
- Q10、Q11、Q14等题目跨越多个阶段
- 允许在多个阶段重复探讨
- 体现认知的复杂性和多维度特性

### 1.3 认知旅程的深度（用户确认）

**深度模式 - 全部探讨**：
- 所有15道题都要进行同等深度的探讨
- 确保完整性和深度，不让任何题目成为"背景数据"
- 每道题的选择（分数+具体回答）都成为针对性追问的基础

## 二、认知旅程框架系统

### 2.1 从"三层桥梁"到"旅程框架系统"

**原有的三层桥梁**：
```
Layer 1: 个性化确认层 → Layer 2: 经验追溯层 → Layer 3: 概念桥接层
```

**新的旅程框架系统**：
```
Layer 0: 风格框架建立层（认知指南针）
    ↓
Layer 1: 结构化认知旅程层（5个阶段，15道题重新访问）
    ↓
Layer 2: 旅程回望重构层（带着新体验重新理解）
    ↓
Layer 3: AI素养概念讨论层（从旅程中自然浮现）
```

```python
class JourneyStateManager:
    """认知旅程状态管理器"""

    def __init__(self):
        self.state = {
            "current_phase": "framework_setup",  # 当前阶段
            "current_journey_stage": 1,         # 当前旅程阶段（1-6）
            "user_framework": None,              # 用户风格框架
            "completed_questions": [],           # 已完成的题目
            "journey_discoveries": [],           # 旅程中的发现
            "framework_adjustments": [],         # 框架调整记录
            "conversation_depth": 0              # 对话深度
        }

    def transition_to_next_stage(self):
        """过渡到下一个旅程阶段"""
        if self.state["current_journey_stage"] < 6:
            self.state["current_journey_stage"] += 1
            return True
        return False

    def record_discovery(self, discovery):
        """记录旅程发现"""
        self.state["journey_discoveries"].append({
            "stage": self.state["current_journey_stage"],
            "discovery": discovery,
            "timestamp": datetime.now()
        })

    def adjust_framework(self, adjustment):
        """记录框架调整"""
        self.state["framework_adjustments"].append({
            "original": self.state["user_framework"],
            "adjustment": adjustment,
            "timestamp": datetime.now()
        })
        self.state["user_framework"] = adjustment
```

```python
class QuestionFollowUpGenerator:
    """题目级追问生成器"""

    def __init__(self):
        self.follow_up_layers = [
            {
                "layer": "experience_elicitation",
                "objective": "追溯具体经历",
                "question_template": "你选择了'{response}'（{score}分）。能详细讲一个相关经历吗？"

            {
                "layer": "detail_probing",
                "objective": "挖掘过程细节",
                "question_template": "当时具体的情况是怎样的？{context_based_probe}",
                "trigger_condition": "user_gave_initial_experience"
            },
            {
                "layer": "framework_connection",
                "objective": "联系风格框架",
                "question_template": "这个经历如何体现了'{framework}'的特征？",
                "trigger_condition": "layer_2_completed"
            },
            {
                "layer": "contradiction_exploration",
                "objective": "探索矛盾与盲区",
                "question_template": "有没有什么时候你的行为和这个选择不一致？",
                "trigger_condition": "detect_contradiction"
            },
            {
                "layer": "reflection_prompt",
                "objective": "引发深度反思",
                "question_template": "通过这个经历，你对'{question_topic}'有什么新的理解？"
            }
        ]

    def generate_question_follow_up(self, question_id, user_score, user_framework):
        """为特定题目生成追问序列"""
        follow_up_sequence = []

        for layer in self.follow_up_layers:
            follow_up_sequence.append({
                "layer": layer["layer"],
                "objective": layer["objective"],
                "question_template": layer["question_template"].format(
                    response=self._get_question_text(question_id),
                    score=user_score,
                    framework=user_framework
                ),
                "trigger_condition": layer.get("trigger_condition")
            })

        return follow_up_sequence

    def get_next_follow_up(self, question_id, conversation_history, current_layer=0):
        """获取下一层追问"""
        # 基于对话历史决定下一层
        if current_layer < len(self.follow_up_layers):
            return self.follow_up_layers[current_layer]
        return None
```

## 八、关键成功因素

1. **15道题的叙事价值充分发挥** - 每道题都是深度追问的起点
2. **风格框架的持续作用** - 贯穿整个旅程的理解框架
3. **旅程可视化** - 用户明确感知进展和方向
4. **跨越性题目的多维度探讨** - Q10、Q11、Q14等在多个阶段重复出现
5. **深度模式的坚持** - 所有15道题都进行同等深度的探讨

---

这个重构方案实现了从"风格类型作为终点"到"风格类型作为认知旅程入口"的根本性转变，让15道题的隐性叙事路径从"背景数据"变为"前景旅程"，每道题的选择都成为深度追问的起点。
