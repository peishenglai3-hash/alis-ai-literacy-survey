# 给开发者：访谈界面问题说明 + 所需代码

> 这是一份请你协助的诊断请求，**不是追责**。v3.3 执行后访谈界面崩坏，我们需要你的代码来判断"该定点重写还是精准补丁"。请尽量一次性发全，避免来回。

---

## 一、问题说明（简短版）

v3.3 设计升级执行后，**访谈界面出现 3 个布局问题**：

1. **滚动没去掉**：页面仍纵向溢出、需要滚动。v3.3 要求的是"一屏可见、零滚动"。
2. **"认知地图"布局没实现**：v3.3 的 spec 是
   - 中央焦点区（题目 + 答案）
   - 右侧觉察带（思维气泡）
   - 下方钻取区（四思考窗口，默认折叠）
   - 用 grid 布局、一屏装下

   但现在的实际效果是：左栏纵向堆叠 + 右栏纵向堆叠的**旧滚动式布局**，新模块（思维气泡 / 四思考窗口 / 跨题关联 / 访谈进度）被塞进右栏纵向堆在一起。

3. **模块互相遮挡**：右栏堆得太满，在不同题目 / 滚动状态下互相挤压，内容看不清。

**核心**：像是把新的空间化布局直接套在了旧的滚动式组件上，两边都没对上。

## 二、需要你提供的代码（请一次性发全）

### ✅ 必须（最高优先）——访谈界面的"布局容器"

就是**决定这些模块怎么排布的那个组件** + 它的样式：

- [ ] 访谈界面的**主容器组件文件**（`.jsx` / `.tsx` / `.vue`）
  - 里面应该包含：阶段标题、当前题目、答案区、导航按钮，以及引用思维气泡 / 四思考窗口等子组件的地方
- [ ] 这个容器的**样式**
  - 普通的 `.css` 文件 / CSS Modules / Tailwind 类名 / styled-components，**你用的是哪种就发哪种**

> 这两个文件是诊断的关键——滚动和遮挡的根源大概率就在这里。

### 📋 次要——子组件清单（只要路径，不用贴内容）

- [ ] 这个页面**引用了哪些子组件**，列文件路径即可：
  - 思维气泡、四思考窗口、访谈进度、跨题关联、输入框、导航按钮等
  - 先不用把这些子组件的内容贴出来，只要知道"容器是怎么拼它们的"

### 💬 补充信息（几句话回答即可）

- [ ] 技术栈：**React 还是 Vue**？样式用 **普通CSS / CSS Modules / Tailwind / styled-components / 其他**？
- [ ] 你**测试时的浏览器视口尺寸**是多少？（遮挡可能是分辨率相关的，比如 1920×1080 还是 1366×768）
- [ ] 有没有**全局滚动容器**？（某个外层 div 或 `body` 设了 `overflow` / `height`）

## 三、我会用这些代码做什么

1. 判定遮挡是**结构性崩坏**（→ 建议对访谈界面定点重写）还是**几个 CSS bug**（→ 给你一份精准补丁清单）
2. 出一份**冻结的布局 spec + 可测试的验收标准**（例如"1920×1080 视口下零纵向滚动、三区全部可见，出现滚动即判定失败"）——无论最终走重写还是补丁，这份 spec 你都直接能用
