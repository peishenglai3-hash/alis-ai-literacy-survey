## 二、目标长什么样

打开随附的 HTML，它是这样的**三区结构**：

```
┌──────────────────────────────┬─────────────────┐
│                              │                 │
│   【中央焦点区】               │  【右侧觉察带】   │
│   阶段/题目/答案/快速输入/导航   │   思维气泡       │
│                              │                 │
├──────────────────────────────┴─────────────────┤
│   【下方钻取区】四思考窗口（横跨整页，默认折叠）       │
└────────────────────────────────────────────────┘
```

**关键：整页一屏装下、不滚动。** 这是我坚持了好几轮的核心诉求（从"手机端滑动"改成"电脑端一屏"）。

## 三、现在的版本 vs 目标，差 3 点

| # | 目标 | 你现在的版本 | 判定 |
|---|------|------|------|
| ❶ **布局** | grid **三区**（焦点 + 觉察 + 钻取） | **左右两栏 7:3**，还是老结构 | ❌ |
| ❷ **滚动** | **一屏可见、零滚动** | **整页仍需纵向滚动** | ❌ 核心诉求未解决 |
| ❸ **钻取区 + 删除清单** | 四思考窗口 = 横跨整页的**独立第三区**；删掉访谈记录大框、删掉"下一问题预览" | 四思考窗口只是**左栏底部一个折叠按钮**；访谈记录大框、"下一问题预览"都还在 | ❌ |

> **最容易误判的点**：你看到"下面折叠了四个思考模块"，可能以为钻取区已经做了。**其实没有**——那只是左栏尾巴的一个折叠按钮，不是横跨整页的独立第三区。整个布局还是"左滚动 + 右气泡"的老两栏。
