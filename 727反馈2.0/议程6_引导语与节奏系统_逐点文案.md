## ① 开场介绍（被访者向）

### 用途说明

- **时机**：访谈开始前，被访者首次接触界面时
- **UI位置**：全屏独立页或overlay
- **任务**：说明主题是"AI素养"、题目来自一套量表、请凭自身经验作答
- **节奏作用**：慢、稳、建信任
- **受众**：被访者（第二人称、平视）

### 文案内容

**标题**：欢迎参加访谈

**正文**：

你好！今天我们想聊聊你平时使用AI的一些经历和感受。

这些问题没有标准答案，也不需要什么专业知识。我们最想听的是你真实的使用经验——无论是积极的、消极的，还是平淡的，都很有价值。

整个访谈大约需要15-20分钟。你可以随时停下来休息，或者不想回答某个问题就跳过。

准备好了吗？我们开始吧。

**按钮**：[准备好了，开始访谈]

### 设计原则对照

| 原则 | 检查 |
|------|------|
| 受众分离（被访者向） | ✅ 用"你"，平视语气，无术语 |
| 去学术化 | ✅ 无"AI素养""量表"等术语，用"问题"替代 |
| 去价值化 | ✅ 无"应该/正确/好/坏"，强调"没有标准答案" |
| 单一任务 | ✅ 只做建信任+说明任务，不夹操作说明 |
| 温暖专业 | ✅ "准备好了吗"温和开场，不过度活泼 |

## ② 访谈者准备页（访谈者向）

### 用途说明

- **时机**：访谈者进入访谈前，被访者不在场或刚到场
- **UI位置**：独立页（替代被删的"即将访谈"内容堆叠页）
- **任务**：操作指引 + 主导策略 + 人格类型→程序过渡 + 录音授权
- **节奏作用**：上场仪式、就位
- **受众**：访谈者（指导语气，可提界面术语和研究框架）

### 文案内容

**标题**：访谈准备指南

**第一段：界面说明**

访谈界面分为三个区域：

- **中央焦点区**（左侧大区）：显示当前题目和受访者的回答。这是你的主要关注区域，用来观察和引导对话。

- **右侧觉察带**（窄条区）：显示"思维气泡"——包括预设问题、跨题关联提醒、你的手动笔记。这是辅助参考，余光扫描即可，不用一直盯着。

- **下方钻取区**（底部，默认折叠）：四个深度思考窗口（题目理解、经验叙事、选择解释、素养关联）。需要时点击展开，平时折叠不占空间。

整个页面设计为一屏可见，无需滚动。在1920×1080分辨率下，三区都在视野内。

**第二段：操作指引**

- **导航**：用"上一题/下一题"按钮切换题目。
- **快速输入**：焦点区底部有输入框，按回车键快速保存受访者的关键回复（关键词式，不是大段转录）。
- **思维气泡**：右侧觉察带会自动显示预设问题。你也可以按回车键手动添加想法。
- **矛盾检测**：如果发现回答中有明显矛盾，系统会在焦点区提示，可选用该提示作为追问。

**第三段：主导策略**

你是这场对话的主导者。系统提供的所有提示（气泡、矛盾检测、思考窗口）都是参考，不是剧本。你可以：

- 按照你的判断选择追问方向
- 忽略系统提示，凭经验引导
- 把系统提示当作"备忘"，不是"指令"

受访者的人格类型结果已经生成。如果需要，你可以在访谈开始前简要介绍这个类型，然后自然过渡到访谈流程。

**第四段：录音授权**

在开始前，请：

1. 确认受访者同意录音
2. 开启录音设备
3. 确认录音正常工作

**第五段：心态准备**

访谈不是考试，也不是审问。是一场对AI使用经验的探索性对话。你的角色是：

- 引导者：保持对话流畅
- 观察者：注意言外之意
- 记录者：保存关键洞察

准备好了吗？

**按钮**：[受访者已到，开始访谈] [先看看题库]

### 设计原则对照

| 原则 | 检查 |
|------|------|
| 受众分离（访谈者向） | ✅ 可用界面术语（觉察带/钻取区），指导语气 |
| 单一任务 | ✅ 五段各自有独立任务，不堆叠 |
| 不堆题库 | ✅ 提供"先看看题库"选项，但不把题目堆在准备页 |
| 专业但不冷 | ✅ "你是主导者"赋权，"不是审问"去压力 |
| 合规明确 | ✅ 录音授权独立成段，步骤清晰 |
