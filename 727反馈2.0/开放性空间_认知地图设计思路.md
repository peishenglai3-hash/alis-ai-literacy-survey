# 开放性空间设计思路：从"问题清单"到"讨论地图"

**设计批评**：之前的8卡片设计是"问题堆积"，缺乏空间感和导航方向。

---

## 🧠 重新理解访谈场景

### 访谈15题结束后发生了什么

**访谈者的状态**：
- 刚刚引导被访者完成15题，可能有点累
- 需要从"提问-记录"模式切换到"讨论-探索"模式
- 需要知道："还有什么可讨论的？""从哪个开始？""为什么要讨论这个？"

**被访者的状态**：
- 刚刚做完15题，可能有点累
- 看到"还有问题"会有压力
- 需要一个"休息+自由讨论"的氛围，不是"考试继续"

**共同的状态**：
- 两人一起看屏幕（不是访谈者单看）
- 不是"访谈者提问，被访者回答"，而是"一起讨论"

### v3.3的空间化智慧

**访谈界面的三区结构**：
```
┌───────────────────────────┬─────────────────┐
│ 【中央焦点区】（60%）      │ 【右侧觉察带】   │
│ 当前题目 + 答案选择        │ 思维气泡         │
│                           │ （余光扫描）     │
├───────────────────────────┴─────────────────┤
│ 【下方钻取区】（默认折叠）                    │
│ 四个思考窗口                                   │
└──────────────────────────────────────────────┘
```

**设计原则**：
- 不争不抢，有主有次
- 一屏可达，不用滚动
- 访谈者是主动的，不是被信息轰炸

---

## 🎨 开放性空间的设计目标

### 目标不是什么

- ❌ 不是"展示所有问题"（问题清单）
- ❌ 不是"必须完成所有任务"（待办清单）
- ❌ 不是"8个平等卡片"（缺乏主次）

### 目标是什么

- ✅ **讨论地图**：让访谈者知道"有哪些可讨论的方向"
- ✅ **导航系统**：让访谈者知道"从哪里开始，往哪里走"
- ✅ **空间感**：让访谈者感受到"我们在认知旅程的哪个位置"
- ✅ **主导性**：让访谈者感到"我可以选择，我理解为什么要这样"

---

## 💡 四种设计思路

### 思路1：认知地图式（推荐）

**隐喻**：访谈刚刚完成，现在是一个"认知地图"，四个话题是四个"区域"。

**布局**：
```
┌─────────────────────────────────┐
│   标题：开放性讨论 · 认知之旅   │
│   "15题结束，我们可以自由探索"  │
└─────────────────────────────────┘

┌───────────────────┬─────────────────┐
│ 【当前焦点区】      │ 【话题导航区】   │
│ （当前选中的话题）  │ （其他话题的方向）│
│                   │                 │
│ 🖊️ 自我反思       │ 📖 ← 概念理解   │
│ [具体问题展开]     │                 │
│                   │ ⭐ ↓ 社会拓展   │
│                   │                 │
│                   │ 📝 → 概念总结   │
│                   │                 │
├───────────────────┴─────────────────┤
│ 【对话记录区】（访谈者记录讨论要点） │
└─────────────────────────────────────┘
```

**交互逻辑**：
1. 默认显示"自我反思"作为焦点（从哪里开始）
2. 右侧导航区显示其他话题的"方向感"（不是详细问题）
3. 点击导航区的图标 → 焦点区切换到该话题
4. 访谈者可以按顺序走，也可以跳着走（有主导性）

**优势**：
- ✅ 有主有次（焦点区是主，导航区是次）
- ✅ 有空间感（话题是"区域"，不是"清单"）
- ✅ 有方向感（箭头暗示讨论可以往哪个方向走）
- ✅ 访谈者有主导性（可以选择顺序）

---

### 思路2：旅程导航式

**隐喻**：15题是一条路径，现在是"休息站+观景台"，可以看到不同的方向。

**布局**：
```
┌─────────────────────────────────┐
│   🎉 15题完成！                  │
│   "现在我们来到开放讨论空间"      │
└─────────────────────────────────┘

┌─────────────────────────────────┐
│   【旅程地图】                    │
│   起点                          │
│     🖊️ 自我反思 ───────────→     │
│                                  │
│     📖 概论理解                  │
│                                  │
│     ⭐ 社会拓展                  │
│                                  │
│     📝 概念总结 ─────────→ 终点  │
│   （当前：🖊️ 自我反思）           │
└─────────────────────────────────┘

┌─────────────────────────────────┐
│   【当前话题】🖊️ 自我反思         │
│   [问题列表]                     │
└─────────────────────────────────┘
```

**交互逻辑**：
1. 顶部庆祝"15题完成"（正向反馈）
2. 中间是旅程地图，显示四个话题的路径关系
3. 底部是当前话题的具体问题
4. 访谈者点击地图上的图标 → 切换话题

**优势**：
- ✅ 有"旅程完成感"（15题结束是里程碑）
- ✅ 有"方向感"（地图显示路径）
- ✅ 有"当前位置感"（当前：🖊️ 自我反思）

---

### 思路3：对话圆桌式

**隐喻**：两人围坐在圆桌旁，四个话题是桌上的"话题卡片"。

**布局**：
```
┌─────────────────────────────────┐
│   💬 开放性讨论 · 共同思考       │
│   "这是我们可以一起探索的话题"    │
└─────────────────────────────────┘

         📖
    ┌─────────┐
    │概念理解 │
    └─────────┘
 ⭐         ┌─────────┐         🖊️
社会拓展    │ 对话    │    自我反思
            │ 中心   │
    ┌─────────┐         │         │
    │概念总结 │           └─────────┘
    └─────────┘                 📝

【当前讨论】🖊️ 自我反思
[问题展开]
```

**交互逻辑**：
1. 中央是"对话中心"，显示当前讨论的问题
2. 四周是四个话题卡片
3. 访谈者点击任一卡片 → 切换到该话题

**优势**：
- ✅ 有"平等对话"感（圆桌隐喻）
- ✅ 有"可探索感"（四周是可选择的话题）

---

### 思路4：分层雷达式

**隐喻**：开放性空间是一个"雷达"，显示不同维度的可讨论方向。

**布局**：
```
┌─────────────────────────────────┐
│   【当前讨论】🖊️ 自我反思         │
│   [问题列表]                     │
└─────────────────────────────────┘

┌─────────────────────────────────┐
│   【讨论雷达】                    │
│                                  │
│       📖                        │
│                                  │
│   ⭐       +       🖊️          │
│              当前                │
│                                  │
│       📝                        │
│                                  │
│   （点击雷达上的图标切换话题）    │
└─────────────────────────────────┘
```

**优势**：
- ✅ 有"全览感"（一眼看到所有方向）
- ✅ 有"当前位置"（中心+标记）

---

## 🎯 推荐方案：认知地图式（思路1）

### 为什么推荐

1. **符合v3.3设计哲学**：中央焦点+周边觉察，有主有次
2. **访谈者有主导性**：可以看到所有方向，可以选择顺序
3. **有空间感和方向感**：话题是"区域"，不是"清单"
4. **减轻压力**：不是"必须完成所有问题"，而是"可以选择探索"
