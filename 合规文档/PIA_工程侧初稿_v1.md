## 一、评估背景与目的

ALIS 是一套用于**学术研究**的个性化访谈工具：以个性化李克特量表测量受访者的 AI 素养，
辅以由大模型生成的**追问语句**引导受访者讲述具体经历，并可采集**语音叙事**。
因处理涉及**语音（含声纹，属敏感个人信息）**且**可能涉及未成年人**，依据《个人信息保护法》
第 55 条，处理前开展本影响评估，评估处理目的与方式的合法性、正当性、必要性，识别对个人权益的风险并落实缓解措施。

**处理目的（限定）**：仅用于本课题的学术研究（AI 素养的测量、刻画与分析），不用于任何商业、评级或自动化决策用途。

## 三、个人信息类别与敏感性

| 数据要素 | 类别 | 是否敏感 | 存储位置 |
|---------|------|:------:|---------|
| 会话标识 `session_id` | 假名标识（UUID） | 否 | 服务器 SQLite |
| 促进者标识 `facilitator_id` | 研究人员标识 | 否 | 服务器 SQLite |
| 时间戳、暴露 A/B 条件、`age_screen_pass`、`consent_ref` | 过程元数据 | 否 | 服务器 SQLite |
| 李克特作答 `raw_score` | 研究测量数据 | 否 | 服务器 SQLite |
| 维度分 / 连续剖面 / 置信区间 / 自命名标签 | 由确定性代码计算的派生数据 | 否 | 服务器 SQLite |
| 叙事**转写文本** `transcript` | 访谈内容 | 视内容可能含敏感信息 | 服务器 SQLite |
| **语音录音（原始音频）** | **声纹＝敏感个人信息** | **是** | **仅采集机本地**（不入服务器、不入库） |
| 音频路径指针 `audio_file_id` | 指向采集机本地文件的引用 | 否（仅指针） | 服务器 SQLite |
| （可能）未成年人相关信息 | **敏感** | **是** | 见未成年人保护安排 |

> **不采集**：真实姓名、身份证件号、住址、精确定位、银行/支付信息等直接身份标识；受访者以假名/编号参与。

## 四、处理目的、方式与必要性（最小化论证）

1. **李克特作答 / 维度分 / 剖面**：测量 AI 素养的直接依据，最小必要。
2. **追问语句渲染**：由大模型把系统**已确定**的追问骨架落成一句自然中文；
   **铁律**——大模型只处理语言、不评分、不选题、不改分支，不引入量表外概念；调用失败自动回退骨架文本。
   仅向大模型传递必要的题面/维度/骨架文本，**不传音频、不传身份标识**。
3. **语音录音**：用于捕捉受访者的**具体叙事经历**（"叙事触发器"）。原始音频**仅用于本地转写**，
   转写文本进入分析；**原始音频不是分析所必需的长期资产**，故设置**≤7 天删除**。
4. **暴露 A/B 条件**：实验设计所需，评估问题暴露对反应的影响。

**必要性结论**：各要素均服务于明确研究目的；对个人权益影响最大的**原始音频**采取"本地转写＋短期删除＋不上云"的最小化处置。

## 五、数据流全景

```
[受访者/促进者·采集机浏览器]
   ├─ 李克特作答 → 浏览器端确定性评分（XState）→ 维度分/剖面
   ├─ 追问：POST /probe/render →(服务器)→ DeepSeek 仅渲染语言 → 追问文本
   ├─ 整包落库：POST /session/commit → 作答/维度分/剖面/AB反应
   └─ 语音录音 → **仅在采集机本地**生成可下载文件
            └─ 促进者另存 → 本地 Whisper 转写 → 核对
                 ├─ POST /narrative/register：仅上传【转写文本 + 路径指针】
                 └─ 原始音频：采集机本地保存，**≤7 天自动删除**
        │  全程经 SSH 加密隧道（浏览器→localhost→云端 127.0.0.1:8000），不开放公网端口
        ▼
[阿里云 ECS·上海·境内]  uvicorn(仅绑 127.0.0.1) + SQLite(境内)
        │  数据导出：/export/bundle.zip（宽/长表+字典+README，含个人数据，仅内网/加密介质取走）
        ▼
   DeepSeek API（境内；仅接收渲染文本；铁律：只渲染语言）
```

**关键事实**：原始音频**从不离开采集机**、**从不入库**；服务器仅持有转写文本与路径指针；
数据与大模型调用**全程境内**，**无跨境**。

## 六、技术与管理安全措施（已实施 / 计划）

**传输**
- 采集设备经 **SSH 加密隧道**访问服务（浏览器命中 `localhost`，满足录音所需安全上下文且加密）；
- 服务**仅监听 127.0.0.1**，**不开放公网端口**；云安全组仅放行 SSH(22)。

**主机与账户**
- SSH **仅密钥登录**（已关闭密码登录）、root 仅密钥；**专用最小权限账户**运行服务；
- 主机防火墙 `ufw` 仅放行 22；`fail2ban` 防暴力破解；系统时区/日志规范化。

**存储**
- 数据库为境内 SQLite，文件目录限权；`.env`（含 API Key）权限 600、**不入版本库/镜像**；
- **原始音频不上云**；采集机侧音频存于指定目录并**≤7 天删除**（脚本 + 计划任务）。

**服务隔离**
- systemd 运行，`NoNewPrivileges`、`PrivateTmp`、`ProtectSystem` 等沙箱项开启；崩溃自恢复。

**备份**
- 每日对数据库做**一致性快照**（SQLite `.backup`），本机留存最近 14 份、目录 700；
- **外发副本须加密、境内存储**，并同样遵守原始音频不外发、期限约束。

**访问控制（管理）**
- 部署私钥**专人保管**、不明文传输；促进者控制台访问限于研究团队；最小必要授权。

**待完善（记录在案）**
- 促进者控制台的登录鉴权【计划：接入口令/令牌】；
- 正式对外阶段：ICP 备案、等保定级、HTTPS/Nginx、对象存储生命周期规则等（8 月学术成果后推进）。

## 七、未成年人与敏感信息的单独同意安排

- **年龄筛查护栏**：会话建立接口对 `age_screen_pass=false` 直接拒绝（HTTP 403），未成年人须转入**监护人知情同意**流程后方可参与。
- **敏感个人信息单独同意**：对**语音录音**等敏感信息的处理，取得**单独、明示**同意（见配套《知情同意/单独同意文案》独立勾选与签名位）。
- **告知充分**：处理目的、方式、种类、保存期限、删除机制、对权益的影响，均在同意前告知。

## 八、个人信息主体权利保障

受访者（及监护人）享有并可行使：查阅、复制、更正、补充、**删除**、**撤回同意**、要求解释说明、投诉举报等权利。
行使方式：联系【项目负责人/联系方式】，团队在【N】个工作日内响应。撤回同意不影响撤回前处理的合法性；撤回后停止继续处理并按约定删除。

## 九、风险识别、影响分析与缓解

| 风险 | 影响 | 缓解措施 | 剩余风险 |
|------|------|---------|:------:|
| 原始音频（声纹）泄露 | 高 | 不上云、仅本地、≤7 天删、访问受限 | 低 |
| 传输被窃听 | 中 | 全程 SSH 加密、不开公网端口 | 低 |
| 主机被入侵 | 中 | 仅密钥登录、ufw、fail2ban、最小账户、沙箱 | 低-中 |
| 转写文本含敏感内容 | 中 | 目的限定、访问控制、导出仅内网/加密介质 | 中 |
| 未成年人未经监护同意参与 | 高 | 年龄筛查护栏 + 监护人同意流程 | 低 |
| 备份副本外泄 | 中 | 加密、境内、限权、期限 | 低 |
| 大模型侧数据外传 | 中 | 仅传渲染文本、不传音频/身份、境内 API、铁律 | 低 |

## 十、结论

在落实上述技术与管理措施的前提下，处理目的正当、方式合法、范围最小；对个人权益影响最大的**原始音频**
采取"不出采集机 + 本地转写 + 短期删除"的最小化处置。**剩余风险总体可控**。
建议在**正式对外采集**前完成：伦理审查、促进者控制台鉴权、以及（8 月学术成果后）备案与等保配套。
本评估随系统演进（如上对象存储、切换数据库、开放公网）**应更新重评**。
