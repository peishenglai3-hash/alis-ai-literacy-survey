```python
def generate_answers_for_type(type_code):
    """
    根据type_code生成对应的answers
    例如：ETF → E高分、T高分、F高分
    """
    # 默认中等分
    answers = {f"Q{i}": 4 for i in range(1, 16)}

    # 根据type_code调整分数
    p1, p2, p3 = type_code[0], type_code[1], type_code[2]

    # 维度1：E-U
    if p1 == "E":
        answers.update({"Q1": 7, "Q2": 7, "Q6": 7})  # 探索端高分
        answers.update({"Q3": 1, "Q4": 1})          # 实用端低分
    else:  # U
        answers.update({"Q1": 1, "Q2": 1, "Q6": 1})  # 探索端低分
        answers.update({"Q3": 7, "Q4": 7})          # 实用端高分

    # 维度2：T-V
    if p2 == "T":
        answers.update({"Q5": 7, "Q7": 7})      # 信任端高分
        answers.update({"Q8": 1, "Q9": 1, "Q12": 1})  # 验证端低分
    else:  # V
        answers.update({"Q5": 1, "Q7": 1})      # 信任端低分
        answers.update({"Q8": 7, "Q9": 7, "Q12": 7})   # 验证端高分

    # 维度3：F-R
    if p3 == "F":
        answers.update({"Q3": 7, "Q4": 7, "Q5": 7, "Q6": 7})  # 功能端高分
        answers.update({"Q10": 1, "Q11": 1, "Q13": 1, "Q14": 1, "Q15": 1})  # 反思端低分
    else:  # R
        answers.update({"Q3": 1, "Q4": 1, "Q5": 1, "Q6": 1})  # 功能端低分
        answers.update({"Q10": 7, "Q11": 7, "Q13": 7, "Q14": 7, "Q15": 7})  # 反思端高分

    return answers
```

```python
        return answers
```

## 常见问题排查

### 问题1：类型代码判定错误

**症状**：预期ETF，实际判定为ERF

**排查步骤**：
1. 检查维度2（T-V）的判定逻辑
2. 验证truster_score和verifier_score的计算
3. 确认Q5,Q7（信任端）和Q8,Q9,Q12（验证端）的分数

### 问题2：百分比计算错误

**症状**：预期90%，实际计算为85%

**排查步骤**：
1. 检查百分比计算公式：`percent = score/7*100`
2. 确认score是平均值（如(7+6+7)/3=6.667）
3. 验证round()函数的使用

### 问题3：出现旧类型名称

**症状**：full_name中出现"AI反思者"

**排查步骤**：
1. 检查type_names字典的键值对
2. 确认type_code计算正确
3. 验证没有使用旧的判定逻辑
