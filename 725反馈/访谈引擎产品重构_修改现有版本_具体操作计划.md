# 访谈引擎产品重构：修改现有版本的具体操作计划

**文档版本**: v1.0
**创建日期**: 2026-07-25
**修改范围**: 从"AI访谈员"到"增强型访谈辅助系统"
**修改优先级**: P0（最高优先级）

---

## 📋 修改清单总览

从5个方面修改现有版本：

1. **交互结构修改**：从"三步流程"改为"四个思考窗口"
2. **界面布局修改**：从"问题卡片"改为"认知地图"
3. **数据结构修改**：建立Question Schema
4. **内容生成修改**：离线生成+人工审核
5. **开发优先级修改**：P0/P1/P2分级

---

## 🎯 修改1：交互结构重构

### 现有版本（错误）

```
❌ 三步深入模板：

💡 引导建议（3步深入）
├─ 第1步：让TA讲具体故事
│  └─ "你什么时候开始注意到AI的？"
├─ 第2步：让TA讲具体经验
│  └─ "能举个具体的例子吗？"
└─ 第3步：让TA反思判断标准
   └─ "有没有什么时候你会不确定'这是不是AI'？"

🎯 类型视角：
"作为好奇猫（摸鱼人型），你倾向于..."
```

**问题诊断**：
- ❌ 这是线性流程，暗示访谈者必须按这个顺序提问
- ❌ 暗示AI"知道该问什么"
- ❌ 固定问题限制思维灵活性
- ❌ 访谈者容易变成"问题朗读者"

---

### 修改后版本（正确）

```
✅ 四个思考窗口（并列呈现）：

【窗口1：题目理解 Meaning】
这个问题在问什么？

关键词：识别 · 分辨 · 判断

可以关注：
- TA如何理解"AI"
- TA认为什么算"真正使用AI"
- TA有没有质疑题目

【窗口2：经验叙事 Experience】
可能的故事入口：

第一次接触：
- 第一次听说AI是什么时候？
- 第一次觉得AI和自己有关？

典型经历：
- 有没有一次经历改变了你对AI的看法？

变化节点：
- 对AI的认识有没有变化？

【窗口3：选择解释 Choice】
你的选择：5分（比较同意）

可能意味着：
- 能够识别AI应用
- 对AI有一定判断标准

探索方向：
- 这种判断来自哪里？
- 为什么是5分而不是6分？

【窗口4：素养关联 Literacy】
研究关联：

本题涉及：
AI识别能力
↓
AI理解能力
↓
技术判断能力

注意区分：
描述知识 vs 描述经验判断
```

**关键改进**：
- ✅ 四个窗口并列呈现（不是线性流程）
- ✅ 访谈者自主选择使用哪个窗口
- ✅ 每个窗口提供"思考方向"，不是"固定问题"
- ✅ AI提供"认知支架"，不是"访谈脚本"

**Step 1：修改前端组件结构**

```jsx
// ❌ 旧组件结构
<div className="question-card">
  <h2>{question.content}</h2>
  <AnswerSelector value={answer} onChange={handleAnswerChange} />

  <TypePerspective type={userType} />

    <button onClick={handlePrevious}>← 上一题</button>
    <button onClick={handleNext}>下一题 →</button>

  {/* 左侧：中央极简区 */}
  <div className="core-question">
    <div className="stage-progress">阶段1: 初识 | Q1/3</div>

    <h2>{question.content}</h2>
    <div className="keywords">
      {question.keywords.map(kw => (
        <span key={kw} className="keyword">
          {kw}
        </span>
      )).join(' · ')}
      <span className="toggle-hint">◇</span>
    </div>

    <AnswerSelector value={answer} onChange={handleAnswerChange} />

    <InterviewNotesInput
      placeholder="记录TA的理解、案例、经验、质疑..."
      value={notes}
      onChange={handleNotesChange}
    />

    {/* 四个思考窗口按钮（可折叠） */}
    <div className="thinking-windows">
      <WindowButton
        name="题目理解"
        isActive={activeWindow === 'meaning'}
        onClick={() => handleToggleWindow('meaning')}
      />
      <WindowButton
        name="经验叙事"
        isActive={activeWindow === 'experience'}
        onClick={() => handleToggleWindow('experience')}
      />
      <WindowButton
        name="选择解释"
        isActive={activeWindow === 'choice'}
        onClick={() => handleToggleWindow('choice')}
      />
      <WindowButton
        name="素养关联"
        isActive={activeWindow === 'literacy'}
        onClick={() => handleToggleWindow('literacy')}
      />
    </div>

    {/* 窗口详细内容（点击后展开） */}
    {activeWindow && (
      <WindowContent
        windowType={activeWindow}
        content={question.thinkingWindows[activeWindow]}
        answer={answer}
        onClose={() => setActiveWindow(null)}
      />
    )}

    <div className="button-group">
      <button onClick={handlePrevious}>← 上一题</button>
      <button onClick={handleNext}>下一题 →</button>
    </div>
  </div>

  {/* 右侧：悬浮面板 */}
  <ThoughtBubblePanel
    mode="focused"
    interviewId={interviewId}
    currentQuestion={question.id}
    currentAnswer={answer}
  />
</div>
```

async function getCrossQuestionAssociations(currentQuestionId, interviewAnswer) {

  // 基于关键词匹配（简化版）
  const associations = [];

  for (const rule of schema.跨题关联) {
    const triggerKeywords = rule.触发关键词;
    const hasKeyword = triggerKeywords.some(kw =>
      interviewAnswer.toLowerCase().includes(kw.toLowerCase())

    if (hasKeyword) {

        相关问题: rule.相关问题,
        关联说明: rule.关联说明,
        探索提示: rule.探索提示

    // ... Q3-Q15
  ];

  const outputDir = path.join(__dirname, '../output');
  if (!fs.existsSync(outputDir)) {
    fs.mkdirSync(outputDir, { recursive: true });
  }

  for (const question of questions) {
    console.log(`正在生成 ${question.question_id} 的Schema...`);

    const schema = await generateQuestionSchema(question);

    if (schema) {
      const outputPath = path.join(outputDir, `${question.question_id}_schema_draft.json`);
      fs.writeFileSync(outputPath, JSON.stringify(schema, null, 2), 'utf8');
      console.log(`✅ ${question.question_id} Schema已生成`);
    }

    // 避免API限流
    await new Promise(resolve => setTimeout(resolve, 1000));
  }

  console.log('所有Schema生成完成！');
}

generateAllSchemas();

const fs = require('fs');
const path = require('path');
const mysql = require('mysql2/promise');

async function importApprovedSchemas() {
  const connection = await mysql.createConnection({
    host: 'localhost',
    user: 'root',
    password: 'your_password',
    database: 'interview_engine'
  });

  try {
    // 读取已审核的Schema文件
    const schemaDir = path.join(__dirname, '../output/approved');
    const schemaFiles = fs.readdirSync(schemaDir)
      .filter(f => f.endsWith('_schema_approved.json'));

    console.log(`找到 ${schemaFiles.length} 个已审核的Schema文件`);

    for (const file of schemaFiles) {
      const schema = JSON.parse(
        fs.readFileSync(path.join(schemaDir, file), 'utf8')
      );

      // 插入数据库
      await connection.query(
        `INSERT INTO question_schemas (
          question_id, content, 关键词, 核心能力, 叙事路径,
          可能误区, 思考窗口, 思维气泡预设, 跨题关联,
          version, 人工审核
        ) VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?)
        ON DUPLICATE KEY UPDATE
          content = VALUES(content),
          关键词 = VALUES(关键词),
          核心能力 = VALUES(核心能力),
          叙事路径 = VALUES(叙事路径),
          可能误区 = VALUES(可能误区),
          思考窗口 = VALUES(思考窗口),
          思维气泡预设 = VALUES(思维气泡预设),
          跨题关联 = VALUES(跨题关联),
          version = VALUES(version),
          人工审核 = VALUES(人工审核)`,
        [
          schema.question_id,
          schema.content,
          JSON.stringify(schema.关键词),
          JSON.stringify(schema.核心能力),
          JSON.stringify(schema.叙事路径),
          JSON.stringify(schema.可能误区),
          JSON.stringify(schema.思考窗口),
          JSON.stringify(schema.思维气泡预设),
          JSON.stringify(schema.跨题关联),
          schema.version,
          true  // 已审核
        ]
      );

      console.log(`✅ 已导入 ${schema.question_id}`);
    }

    console.log('所有Schema导入完成！');

  } catch (error) {
    console.error('导入失败:', error);
  } finally {
    await connection.end();
  }
}
