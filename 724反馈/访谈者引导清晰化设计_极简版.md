# 访谈者引导清晰化设计（极简版）

**创建日期**: 2026-07-24
**基于**: v3.0访谈流程设计
**核心目标**: 简洁、直观、减少认知负担

---

## 一、问题诊断

### 当前问题（基于用户反馈）

**问题1：类型悬浮窗信息过多**
- ❌ 只显示"类型：AI摸鱼人（好奇猫型）"
- ❌ 访谈者不知道这个类型意味着什么
- ❌ 不知道从什么角度提问

**问题2：引导建议过于复杂**
- ❌ 多层嵌套结构（叙事起点→连接→深入→开放式）
- ❌ 文案过长，不符合口语直觉
- ❌ 访谈者不知道"要干嘛"、"看什么"
- ❌ 增加认知负担而非减轻

**核心矛盾**：
- 设计者想提供"完整的引导思路"
- 访谈者只需要"快速理解、灵活使用"

---

## 二、解决方案总览

### 设计原则

1. **极简原则**：信息密度最小化
2. **直观原则**：一眼看懂，无需思考
3. **灵活原则**：明确是"参考"不是"脚本"
4. **口语原则**：短句、日常化、不学术

## 四、问题7解决方案：引导建议简化

### 4.1 简化策略（保留逻辑递进）

**旧设计（过于术语化）**：
```
💡 故事化引导（由浅入深）
├─ 📖 叙事起点（激发回忆）
│  "你什么时候开始开始注意到AI的存在？"
├─ 🔗 连接：从"能够分辨AI"（Q1=6）出发
├─ 🎯 激发叙述：人如何划定AI边界
└─ 💬 开放式追问：典型例子、例外情况
```

**问题**：
- 专业术语过多（"叙事起点"、"激发叙述"、"激发叙述"）
- 不知道"为什么要这么问"
- 不知道如何层层深入

---

**新设计（保留逻辑，去术语化）**：

```
┌─────────────────────────────────┐
│ 💡 引导思路（3步深入）          │
│ ───────────────────────────────│
│                                  │
│ 第1步：让TA讲具体故事            │
│ "你什么时候开始注意到AI的？"      │
│ → 为什么：从回忆开始，让受访者放│
│   松，容易开口                   │
│                                  │
│ 第2步：让TA讲具体经验            │
│ "能举个具体的例子吗？"           │
│ → 为什么：从抽象到具体，获得可  │
│   分析的材料                     │
│                                  │
│ 第3步：让TA反思判断标准          │
│ "有没有什么时候你会不确定'这是不 │
│  是AI'？"                        │
│ → 为什么：从描述到反思，探索判断 │
│   背后的逻辑                     │
│                                  │
│ ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━│
│ 💬 额外追问（可选）              │
│ "有没有你判断错的时候？"         │
│ "你是怎么发现的？"               │
└─────────────────────────────────┘
```

**核心改进**：
1. ✅ 保留3层递进逻辑：故事→经验→反思
2. ✅ 保留"为什么要这么问"的逻辑说明
3. ✅ 用日常语言：不用"叙事起点"，用"让TA讲具体故事"
4. ✅ 简化表述：直接说"为什么"，不用"连接逻辑"
5. ✅ 明确每步的目的：帮助访谈者学习

### 4.3 简化原则总结（保留逻辑递进）

| 设计维度 | 旧设计（术语化） | 新设计（去术语化） |
|---------|----------------|------------------|
| **标题** | 💡 故事化引导（由浅入深） | 💡 引导思路（3步深入） |
| **结构** | 4层嵌套（叙事起点→连接→激发→开放式） | 3步递进（第1步→第2步→第3步+额外追问） |
| **语言** | 专业术语（"激发叙述"、"叙事起点"） | 日常语言（"让TA讲具体故事"、"让TA反思"） |
| **逻辑说明** | "连接逻辑"、"激发叙述" | "为什么：从回忆开始，让受访者放松" |
| **教育意义** | 隐含（需要访谈自己理解） | 明确（直接说明为什么要这么问） |
| **自由度** | 暗示（未明确） | 明确标注"额外追问（可选）" |
| **阅读时间** | 20-30秒（需要理解术语） | 10-15秒（快速浏览，理解逻辑） |

**核心保留**：
- ✅ 3层递进逻辑（叙事→体验→反思）
- ✅ "为什么要这么问"的逻辑说明
- ✅ 教育意义（帮助访谈者学习如何访谈）

**核心改进**：
- ✅ 去掉所有学术术语
- ✅ 用日常语言（"让TA讲具体故事"代替"叙事起点"）
- ✅ 直接说"为什么"，不用"连接逻辑"
- ✅ 简化表述，更直白

## 八、对比评估

### 8.1 改进前后对比（保留逻辑递进版）

| 评估维度 | 改进前（术语化） | 改进后（去术语化） |
|---------|----------------|------------------|
| **阅读时间** | 20-30秒（理解术语+结构） | 10-15秒（浏览3步，理解逻辑） |
| **认知负担** | 高（理解"叙事起点"、"激发叙述"等术语） | 中（理解"让TA讲"、"让TA反思"等日常语言） |
| **逻辑递进** | ✅ 有（但被术语掩盖） | ✅ 清晰（第1步→第2步→第3步） |
| **教育意义** | 隐含（需要访谈自己悟） | 明确（直接说"为什么"） |
| **自由度明确** | 暗示（未标注） | 明确（标注"额外追问（可选）"） |
| **语言风格** | 学术化（"激发叙述"、"叙事起点"） | 口语化（"让TA讲"、"为什么"） |
| **符合直觉** | 低（需要学习术语） | 高（日常语言，秒懂） |

**改进后的优势**：
- ✅ 保留了原有的逻辑递进性（叙事→体验→反思）
- ✅ 保留了教育意义（帮助访谈者学习）
- ✅ 去掉了学术术语，用日常语言
- ✅ 明确了"为什么要这么问"，不用猜测
- ✅ 标注了"可选"，访谈者更灵活

## 十二、总结

### 核心改进

1. **类型悬浮窗**：从"复杂描述"改为"3个核心特征"
2. **引导建议**：从"4层嵌套+术语化"改为"3步递进+日常语言"
3. **逻辑递进**：保留"叙事→体验→反思"的深入结构
4. **教育意义**：明确"为什么要这么问"，帮助访谈者学习
5. **自由度**：明确标注"额外追问（可选）"
6. **语言风格**：从"学术化"（"叙事起点"）改为"口语化"（"让TA讲具体故事"）

### 设计哲学

**保留核心价值**：
- ✅ 保留逻辑递进（叙事→体验→反思）
- ✅ 保留教育意义（帮助访谈者学习）
- ✅ 保留"为什么要这么问"的逻辑说明

**去掉认知负担**：
- ❌ 去掉学术术语
- ❌ 去掉嵌套结构
- ❌ 去掉隐含假设

**访谈者主导**：
- 明确标注"可选"
- 强调"你主导访谈"
- 引导只是"灵感来源"，不是"固定脚本"

**符合直觉**：
- 日常语言，秒懂
- 3步清晰，容易记忆
- 快速浏览，灵活使用
