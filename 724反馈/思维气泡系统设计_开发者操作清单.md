# 思维气泡系统设计 - 开发者操作清单

**核心理念**：从"记录信息"到"记录思路"

**设计目标**：
- 帮助访谈者捕捉灵感、防止遗忘
- 让访谈者的思维过程可视化
- 访谈后能够反思和回顾提问策略

**创建日期**: 2026-07-24
**版本**: v2.0 (融入极简化设计与访谈模式切换)
**10天MVP开发时间**: 1天（简化版）

---

## ⚠️ 10天MVP开发策略

### 开发原则

> **"可以开发简化版（1天），但必须确保不影响核心功能的开发进度"**

### 分阶段实施

**阶段1：MVP核心（Day 1-8）** - 优先级最高
- 必须完成：题目+答案可视化
- 必须完成：故事化引导建议
- 必须完成：类型信息展示

**阶段2：思维气泡简化版（Day 9）** - 仅当核心功能完成后
- 如果时间允许：开发简化版（1天）
- 如果时间不够：**果断跳过**，不影响核心功能

**阶段3：后期优化（MVP完成后）** - 根据用户反馈
- 根据访谈者反馈决定是否继续优化
- 添加高级功能（导出、提醒、模式切换等）

### 风险控制

**核心原则**：
> **思维气泡系统是"锦上添花"的功能，不是"雪中送炭"的功能。**
> **在任何情况下，都不应该挤占核心功能的开发时间。**

**决策树**：
```
Day 8检查点：
  核心功能是否全部完成？
    ├─ 是 → 开发思维气泡简化版（Day 9）
    └─ 否 → 跳过思维气泡系统，继续优化核心功能
```

## 二、数据库设计

### 2.1 创建数据表

```sql
CREATE TABLE thought_bubbles (
    id INT PRIMARY KEY AUTO_INCREMENT,
    interview_id VARCHAR(50) NOT NULL,  -- 访谈ID
    bubble_id VARCHAR(100) NOT NULL UNIQUE,  -- 气泡唯一标识

    -- 气泡内容
    content TEXT NOT NULL,  -- 用户输入的内容

    -- 气泡状态
    status ENUM('pending', 'processed') DEFAULT 'pending',  -- 待处理 | 已处理

    -- 上下文信息（可选）
    current_question VARCHAR(10),  -- 记录是哪道题时产生的
    question_answer INT,  -- 当时的题目答案

    -- 时间戳
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    processed_at TIMESTAMP NULL,  -- 点击"处理"的时间

    -- 索引
    INDEX idx_interview_id (interview_id),
    INDEX idx_status (status),
    INDEX idx_created_at (created_at)
);

COMMENT ON TABLE thought_bubbles IS '访谈者的思维气泡记录表';
```

### 2.2 数据表字段说明

| 字段 | 类型 | 说明 | 示例 |
|------|------|------|------|
| `id` | INT | 主键 | 自增 |
| `interview_id` | VARCHAR(50) | 访谈ID | "interview_20250724_001" |
| `bubble_id` | VARCHAR(100) | 气泡唯一标识 | "bubble_20250724_142835" |
| `content` | TEXT | 气泡内容 | "受访者提到'看是否需要联网'判断AI" |
| `status` | ENUM | 气泡状态 | "pending" 或 "processed" |
| `current_question` | VARCHAR(10) | 当前题目（可选） | "Q1" |
| `question_answer` | INT | 题目答案（可选） | 6 |
| `created_at` | TIMESTAMP | 创建时间 | "2025-07-24 14:28:35" |
| `processed_at` | TIMESTAMP | 处理时间 | "2025-07-24 14:35:20" |

## 三、后端API设计

### 3.1 创建气泡API

**端点**: `POST /api/bubbles/create`

**请求体**:
```json
{
  "interview_id": "interview_20250724_001",
  "content": "受访者提到'看是否需要联网'判断AI",
  "current_question": "Q1",
  "question_answer": 6
}
```

**响应**:
```json
{
  "success": true,
  "bubble": {
    "id": 123,
    "bubble_id": "bubble_20250724_142835",
    "content": "受访者提到'看是否需要联网'判断AI",
    "status": "pending",
    "current_question": "Q1",
    "question_answer": 6,
    "created_at": "2025-07-24 14:28:35"
  }
}
```

**实现示例** (Node.js + Express):
```javascript
// POST /api/bubbles/create
router.post('/create', async (req, res) => {
  try {
    const { interview_id, content, current_question, question_answer } = req.body

    // 生成气泡ID
    const bubble_id = `bubble_${Date.now()}`

    // 插入数据库
    const result = await db.query(
      `INSERT INTO thought_bubbles
       (interview_id, bubble_id, content, current_question, question_answer)
       VALUES (?, ?, ?, ?, ?)`,
      [interview_id, bubble_id, content, current_question, question_answer]
    )

    // 返回创建的气泡
    const bubble = await db.query(
      'SELECT * FROM thought_bubbles WHERE id = ?',
      [result.insertId]
    )

    res.json({
      success: true,
      bubble: bubble[0]
    })
  } catch (error) {
    console.error('创建气泡失败:', error)
    res.status(500).json({
      success: false,
      error: '创建气泡失败'
    })
  }
})
```

**实现示例** (Node.js + Express):
```javascript
// GET /api/bubbles/list
router.get('/list', async (req, res) => {
  try {
    const { interview_id, status, limit } = req.query

    let query = 'SELECT * FROM thought_bubbles WHERE interview_id = ?'
    const params = [interview_id]

    if (status) {
      query += ' AND status = ?'
      params.push(status)
    }

    // 极简模式：限制返回数量
    if (limit) {
      query += ' ORDER BY created_at DESC LIMIT ?'
      params.push(parseInt(limit))
    } else {
      query += ' ORDER BY created_at DESC'
    }

    const bubbles = await db.query(query, params)

    // 获取统计信息
    const countQuery = `
      SELECT
        SUM(CASE WHEN status = 'pending' THEN 1 ELSE 0 END) as pending_count,
        SUM(CASE WHEN status = 'processed' THEN 1 ELSE 0 END) as processed_count
      FROM thought_bubbles
      WHERE interview_id = ?
    `
    const counts = await db.query(countQuery, [interview_id])

    res.json({
      success: true,
      bubbles,
      total: {
        pending: counts[0].pending_count || 0,
        processed: counts[0].processed_count || 0
      }
    })
  } catch (error) {
    console.error('获取气泡列表失败:', error)
    res.status(500).json({
      success: false,
      error: '获取气泡列表失败'
    })
  }
})
```

### 4.2 完整脚本实现（融入模式切换逻辑）

```vue
<script>
import { ref, computed, onMounted } from 'vue'
import axios from 'axios'

export default {
  name: 'ThoughtBubblePanel',

  props: {
    interviewId: {
      type: String,
      required: true
    },
    currentQuestion: {
      type: String,
      default: ''
    },
    currentAnswer: {
      type: Number,
      default: null
    }
  },

  setup(props) {
    const currentThought = ref('')
    const bubbles = ref([])
    const isExpanded = ref(false)
    const inputRef = ref(null)
    const isLoading = ref(false)
    const mode = ref('focused')  // 'focused' | 'record'
    const inputFocused = ref(false)
    const pendingCount = ref(0)
    const processedCount = ref(0)

    // 计算属性
    const pendingBubbles = computed(() => {
      return bubbles.value
        .filter(b => b.status === 'pending')
        .sort((a, b) => new Date(b.created_at) - new Date(a.created_at))
    })

    const processedBubbles = computed(() => {
      return bubbles.value
        .filter(b => b.status === 'processed')
        .sort((a, b) => new Date(b.processed_at) - new Date(a.processed_at))
    })

    const hasProcessedBubbles = computed(() => {
      return processedBubbles.value.length > 0
    })

    // 极简模式：只显示最新2-3个气泡
    const displayBubbles = computed(() => {
      if (mode.value === 'focused') {
        return pendingBubbles.value.slice(0, 3)
      } else {
        return pendingBubbles.value
      }
    })

    // 方法
    const createBubble = async () => {
      if (!currentThought.value.trim() || isLoading.value) return

      const tempContent = currentThought.value
      currentThought.value = ''
      isLoading.value = true

      try {
        const response = await axios.post('/api/bubbles/create', {
          interview_id: props.interviewId,
          content: tempContent,
          current_question: props.currentQuestion,
          question_answer: props.currentAnswer
        })

        if (response.data.success) {
          bubbles.value.unshift(response.data.bubble)
          pendingCount.value++
          isLoading.value = false

          // 如果在深度倾听模式，创建后自动切换到快速记录模式
          if (mode.value === 'focused') {
            // 不自动切换，保持当前模式
          }
        }
      } catch (error) {
        console.error('创建气泡失败:', error)
        isLoading.value = false
        currentThought.value = tempContent  // 恢复内容
      }
    }

    const markAsProcessed = async (bubbleId) => {
      try {
        const response = await axios.put(`/api/bubbles/${bubbleId}/process`)

        if (response.data.success) {
          const index = bubbles.value.findIndex(b => b.bubble_id === bubbleId)
          if (index !== -1) {
            bubbles.value[index] = response.data.bubble
            pendingCount.value--
            processedCount.value++
          }
        }
      } catch (error) {
        console.error('标记气泡失败:', error)
      }
    }

    const formatTime = (isoString) => {
      if (!isoString) return ''
      const date = new Date(isoString)
      return date.toLocaleTimeString('zh-CN', {
        hour: '2-digit',
        minute: '2-digit'
      })
    }

    const toggleProcessed = () => {
      isExpanded.value = !isExpanded.value
    }

    const addNewline = () => {
      currentThought.value += '\n'
    }

    const switchMode = (newMode) => {
      mode.value = newMode
    }

    const switchToRecordMode = () => {
      mode.value = 'record'
    }

    const loadBubbles = async () => {
      try {
        const limit = mode.value === 'focused' ? 3 : null
        const response = await axios.get('/api/bubbles/list', {
          params: {
            interview_id: props.interviewId,
            limit
          }
        })

        if (response.data.success) {
          bubbles.value = response.data.bubbles
          pendingCount.value = response.data.total.pending
          processedCount.value = response.data.total.processed
        }
      } catch (error) {
        console.error('加载气泡失败:', error)
      }
    }

    // 生命周期
    onMounted(() => {
      loadBubbles()
    })

    return {
      currentThought,
      bubbles,
      isExpanded,
      inputRef,
      isLoading,
      mode,
      inputFocused,
      pendingCount,
      processedCount,
      pendingBubbles,
      processedBubbles,
      hasProcessedBubbles,
      displayBubbles,
      createBubble,
      markAsProcessed,
      formatTime,
      toggleProcessed,
      addNewline,
      switchMode,
      switchToRecordMode
    }
  }
}
</script>
```

## 七、风险控制

### 风险识别

| 风险 | 概率 | 影响 | 应对措施 |
|------|------|------|---------|
| 核心功能开发延期 | 高 | 高 | 思维气泡系统优先级降为最低 |
| 思维气泡开发超时 | 中 | 中 | 简化功能，砍掉模式切换 |

| 用户使用率低 | 高 | 低 | 后期根据反馈决定是否保留 |

### 风险应对原则

**原则1：核心功能优先**
> 在任何情况下，都不应该因为思维气泡系统而影响核心功能的开发进度和质量。

**原则2：可随时放弃**
> 思维气泡系统是"锦上添花"的功能，如果开发过程中遇到任何阻碍，应该随时准备放弃。

**原则3：简化优先**
> 如果时间不够，优先保证最基础的功能可用，而不是追求完美。
