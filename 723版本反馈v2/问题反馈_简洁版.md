# 访谈引擎界面问题反馈

**反馈日期**: 2026-07-23
**核心问题**: 追问建议质量差，缺乏叙事引导，无法支持访谈者进行智能化提问

---

## 问题1：追问建议过于模板化，缺乏叙事连贯性

### 当前问题
```
现状提问：
- "如何理解这道题？"
- "想到了什么具体内容和事件？"
- "为什么做这个选择？"
- "有什么困惑的？"
```

### 问题诊断
- 提问像"考试题"或"问卷核对"，不像"访谈引导语"
- 放之四海而皆准，缺乏针对性
- 无法激发被访者的叙事意愿

### 期望效果
**建立连贯叙事**：从认识→使用→如何使用，由浅入深

**正确示例**（阶段1：认识AI）：
```
叙事起点（浅层）：
"你什么时候开始注意到AI的存在？是某个具体的产品、新闻，还是别人的推荐？"

深化方向（中层）：
"第一次意识到'这个应用用了AI'时的情景是什么？那个瞬间让你对AI有了什么具体的印象？"

反思引导（深层）：
"现在回看，你当时对AI的判断准确吗？有什么新的理解？"
```

### 修正方案
**实现分层递进的叙事引导**：
- 第1层：叙事起点（激发回忆）- 从时间点切入
- 第2层：深化方向（关键场景）- 从具体场景深化
- 第3层：反思引导（从经验到理解）- 形成认知闭环

## 问题2：追问建议缺乏语境说明

### 当前问题
```
现状：只显示问题，无解释
Q1: 如何判断AI？
Q2: AI能力边界在哪里？
```

### 问题诊断
- 访谈者不知道"为什么要问这个问题"
- 访谈者不知道"这个问题和原题答案的关系"
- 访谈者不知道"这个问题能帮我获得什么信息"

### 期望效果
**每条追问必须包含三层信息**：

**第1层：与原题答案的连接**
```
🔗 连接：Q1(6)表示受访者能够清晰地分辨AI应用。
故事化引导从"能够分辨"出发，追溯这种能力的形成过程。
```

**第2层：为什么这个引导有效**
```
💡 为什么有效：
从时间点切入，帮助被访者回忆具体事件。
问题开放但不抽象，受访者容易回答，故事自然开始。
```

**第3层：预期访谈收获**
```
🎯 预期收获：
- 受访者第一次接触AI的时间点
- 触发AI注意的具体产品/事件
- 受访者当时对AI的初始印象
```

### 修正方案
**在界面中展示完整上下文**：
```
┌──────────────────────────────────────┐
│ 💡 故事化引导                        │
│ "你什么时候开始注意到AI的存在？"      │
│                                      │
│ 🔗 连接：从"能够分辨AI"（Q1=6）      │
│         出发，追溯AI认知的形成起点   │
│                                      │
│ 💡 为什么有效：时间点切入，容易回忆  │
│                                      │
│ 🎯 预期收获：时间点、触发事件、初始印象│
└──────────────────────────────────────┘
```

## 问题3：没有回到原题，被访者难以回忆

### 当前问题
```
现状：追问与原题脱节
阶段1：认识AI
追问建议：能分享一个识别AI的例子吗？
（界面没有显示Q1的题目和答案）
```

### 问题诊断
- 被访者可能忘记Q1问的是什么
- 被访者可能忘记自己选了什么
- 缺乏"回忆当时的思考过程"的线索

### 期望效果
**界面必须始终显示**：
1. **原题内容**
2. **用户答案**（包括选择的含义）
3. **故事化引导**（基于原题答案生成）

### 修正方案
**界面布局调整**：

```
┌──────────────────────────────────────────────┐
│ 📝 当前讨论：Q1                               │
│ ────────────────────────────────────────────│
│ 我能够清楚地分辨一个应用是否真正使用了AI     │
│                                              │
│ 受访者答案：⭐⭐⭐⭐⭐⭐ 6 - 非常同意        │
│ 含义：受访者在日常生活中能够清晰判断AI应用   │
└──────────────────────────────────────────────┘
                    ↓
┌──────────────────────────────────────────────┐
│ 💡 故事化引导（基于Q1=6生成）                │
│ "你什么时候开始注意到AI的存在？"              │
└──────────────────────────────────────────────┘
```

**核心设计逻辑**：
```
第一步：回到原题
访谈者："Q1你选了'非常同意'，还记得当时怎么考虑的吗？"
→ 帮助被访者回忆

第二步：故事化引导
访谈者："说到识别AI，你什么时候开始注意到AI？"
→ 从回忆转向叙事

第三步：由浅入深
访谈者："第一次意识到'这个应用用了AI'时的情景是什么？"
→ 叙事深入
```

## 问题4：模块之间缺乏过渡引导

### 当前问题
```
现状：阶段间无连接提示
阶段1：认识AI (完成)
阶段2：使用AI (进行中)
[没有过渡提示，访谈者不知道如何自然转向]
```

### 问题诊断
- 访谈者不知道如何从一个阶段过渡到下一个阶段
- 6个阶段的叙事逻辑没有体现
- 访谈容易变成"一题一题核对"，而非"连贯的故事旅程"

### 期望效果
**提供6阶段叙事结构 + 过渡建议**

**6阶段叙事逻辑**：
```
阶段1: 认识AI (Q1, Q2)
  ↓ 叙事逻辑：从抽象认知到具体使用
阶段2: 使用AI (Q3-Q6)
  ↓ 叙事逻辑：从使用行为到信任判断
阶段3: 信任AI (Q7-Q9, Q12)
  ↓ 叙事逻辑：从个人信任到社会视角
阶段4: 与AI相处 (Q10, Q11, Q14)
  ↓ 叙事逻辑：从个人相处到宏观理解
阶段5: 理解AI (Q10, Q11深入)
  ↓ 叙事逻辑：从理解到重新定义
阶段6: 重新定义AI (Q14, Q15深入)
```

### 修正方案
**界面中增加"访谈旅程地图"**：

```
┌──────────────────────────────────────────────┐
│ 🗺️ 访谈旅程地图                               │
│ ────────────────────────────────────────────│
│ ✅ 阶段1: 认识AI (Q1, Q2)                    │
│ 🔄 阶段2: 使用AI (Q3-Q6) [当前]              │
│    └─ 已讨论: Q3, Q4 | 待讨论: Q5, Q6        │
│ ⏳ 阶段3: 信任AI (Q7-Q9, Q12)               │
│ ⏳ 阶段4: 与AI相处 (Q10, Q11, Q14)           │
│ ⏳ 阶段5: 理解AI (Q10, Q11深入)              │
│ ⏳ 阶段6: 重新定义AI (Q14, Q15深入)          │
│                                              │
│ 💡 过渡建议（当阶段2完毕后）：                │
│ "你刚才分享了使用AI的经历。那在使用过程中，   │
│  你如何判断什么时候值得相信AI的结果？"        │
│ 🎯 叙事逻辑：从"如何使用"（行为）             │
│           过渡到"如何判断可信赖性"（态度）   │
└──────────────────────────────────────────────┘
```

## 核心修正原则

1. **避免模板化提问**
   - ❌ "如何理解这道题？"
   - ❌ "想到了什么具体内容和事件？"
   - ❌ "为什么做这个选择？"

2. **实现故事化引导**
   - ✅ "你什么时候开始注意到AI的存在？"
   - ✅ "第一次意识到'这个应用用了AI'时的情景是什么？"
   - ✅ "现在回看，你当时对AI的判断准确吗？"

3. **提供完整上下文**
   - ✅ 连接说明（与原题答案的关系）
   - ✅ 为什么有效（工作原理）
   - ✅ 预期收获（能获得什么信息）

4. **始终回到原题**
   - ✅ 题目+答案始终可见
   - ✅ 引导基于原题答案生成
