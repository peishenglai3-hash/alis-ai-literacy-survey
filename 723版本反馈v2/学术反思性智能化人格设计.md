# AI素养访谈引擎 - 学术反思性智能化人格设计

**创建日期**: 2026-07-23
**核心目标**: 将学术反思性融入访谈引擎，使其成为具有批判性思维的智能助手
**关键理念**: AI素养不是学者定义的概念，而是普通人如何在日常实践中认识、理解、与AI交互

---

## 一、引擎的智能化人格定位

### 1.1 核心定位：共同探索者

**引擎不是**：
- ❌ 权威的"测试工具"
- ❌ 定义AI素养的"专家系统"
- ❌ 给出标准答案的"知识库"

**引擎是**：
- ✅ 共同探索AI素养的"研究者"
- ✅ 保持批判性反思的"对话伙伴"
- ✅ 帮助访谈者深度挖掘的"启发助手"

### 1.2 智能人格的三大特质

**特质1：反思性**
- 对测试题目本身保持反思
- 提醒访谈者："这些问题本身就是对AI素养的一种预设，受访者的回答可能挑战这些预设"

**特质2：批判性**
- 对"AI素养"这个概念保持批判性距离
- 引导访谈者探索：这个概念在受访者的经验世界中有何意义？

**特质3：开放性**
- 承认"AI素养"是"尚未被定义的能力"
- 将访谈定位为"共同探索"，而非"测量评估"

## 二、界面策略：在何处融入反思性

### 策略1：访谈开始的"定位说明"（必须）

**位置**：访谈者第一次打开引擎时

**设计**：
```
┌─────────────────────────────────────────────────────────────┐
│  🎯 AI素养访谈引擎 - 学术说明                                │
│  ─────────────────────────────────────────────────────────  │
│                                                              │
│  关于这个访谈：                                              │
│  ─────────────────────────────────────────────────────────  │
│  AI素养不是一个由学者预先定义的"标准能力"，                │
│  而是普通人在日常生活中如何认识、理解、与AI交互的实践智慧。  │
│                                                              │
│  这个访谈的目的不是"测量受访者的AI素养高低"，                │
│  而是"和受访者一起探索：AI素养可能是什么？"                  │
│                                                              │
│  作为访谈者，你的角色是：                                    │
│  ✅ 保持开放性：不要急于定义，而是探索                        │
│  ✅ 保持反思性：时刻反思"我们这个问题预设了什么？"            │
│  ✅ 保持批判性：鼓励受访者质疑题目和概念的合理性              │
│                                                              │
│  访谈过程中，引擎会在关键时刻提供反思性提示。                │
│                                                              │
│  [我理解了] [开始访谈]                                       │
└─────────────────────────────────────────────────────────────┘
```

**效果**：
- ✅ 在访谈开始时设定学术反思性基调
- ✅ 明确访谈者的角色和态度
- ✅ 建立访谈者与引擎的"共同探索者"关系

```vue
    </div>
  </div>

```

**关键题目的第4层示例**：

**Q1（分辨AI应用）**：
```
🔬 概念反思：
"说到'分辨AI应用'，我们这个测试预设了'能够分辨=AI素养高'。
 但在你的经验中，'分辨AI'对你意味着什么？
 它一定是一种'能力'吗？还是某种别的什么？"
```

**Q7（信任AI）**：
```
🔬 概念反思：
"说到'信任AI'，我们这个测试预设了'愿意信任=AI素养高'。
 但在你的经验中，'信任'是褒义词吗？
 还是说，有时候'不信任'反而是一种更清醒的判断？"
```

**Q10（AI的社会影响）**：
```
🔬 概念反思：
"说到'AI的社会影响'，我们可能预设了'关注社会影响=AI素养高'。
 但在你的经验中，'关注社会影响'意味着什么？
 它是一种责任，还是一种负担？"
```

**Q15（重新定义AI）**：
```
🔬 概念反思：
"在整个访谈中，我们一直在探索'AI素养'这个概念。
 现在，如果让你用自己的话重新定义'AI素养'，你会怎么说？
 它可能是一种什么样的'社会能力'？"
```

**效果**：
- ✅ 在故事化引导中自然融入学术反思
- ✅ 不破坏叙事流程，而是深化叙事
- ✅ 只在关键题目显示，避免过度学术化

**位置**：引擎的某个固定位置（如顶部或侧边栏）

```vue

      <ul>

    </div>
  </div>
</template>
```

**效果**：
- ✅ 引擎主动声明自己的局限

```
└─────────────────────────────────────────────────────────────┘
```

### 4.3 如何（How）：深入程度和语言风格

**深入程度**：
- ❌ 不时刻保持深度（避免过度学术化）
- ✅ 在关键问题深入（Q1, Q7, Q10, Q15）
- ✅ 在访谈开始和结束时系统总结

**语言风格**：
- ❌ 避免过于学术化的术语（"认识论批判"、"解构"）
- ✅ 使用访谈者易懂的语言（"这个问题预设了什么"、"你怎么理解"）
- ✅ 保持对话性（"你觉得"、"你认为"）

**平衡艺术**：
- ✅ 在"故事化引导"（激发叙事）和"概念反思"（学术批判）之间保持平衡
- ✅ 在"开放性"（多种可能）和"聚焦性"（具体问题）之间保持平衡
- ✅ 在"引导性"（提供思路）和"灵活性"（可调整可忽略）之间保持平衡

## 七、总结：如何确保稳定的智能化人格

### 核心原则

1. **元认知声明**：引擎主动声明自己的局限和定位
2. **概念反思**：对测试题目和概念保持批判性距离
3. **开放探索**：将访谈定位为"共同探索"，而非"测量评估"
4. **平衡艺术**：在故事化引导和概念反思之间保持平衡

### 技术实现建议

**如何确保稳定的智能化人格**：

1. **文案模板化**：
   - 访谈开始的"定位说明"：固定文案
   - 引擎的"元认知"声明：固定文案
   - 概念总结专栏：固定文案

2. **引导生成规则化**：
   - 第4层"概念反思"：针对4个关键题目（Q1, Q7, Q10, Q15）
   - 每个题目的第4层：预设2-3个反思引导模板
   - 根据受访者的分数和类型，匹配最合适的模板

3. **概念解构引导**：
   - 针对6个关键概念（AI应用、能力边界、信任AI、AI素养、社会影响、隐私保护）
   - 每个概念准备2-3个解构引导模板

### 优先级排序（10天MVP）

**必须完成（P0.5）**：
- 策略1：访谈开始的"定位说明"（0.5天）

**强烈建议（P1）**：
- 策略2：关键题目的第4层概念反思（1天，4个题目）
- 策略3：访谈结束的概念总结专栏（1天）

**可选优化（P2）**：
- 策略4：轻量级概念反思提示（1-2天）
- 策略5：引擎的"元认知"声明（0.5-1天）
- 策略6：关键概念的"解构引导"（2-3天）
