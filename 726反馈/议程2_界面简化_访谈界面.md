### 关于右侧思维气泡（ThoughtBubble）

根据v3_725设计，思维气泡是**独立悬浮**的辅助工具，不属于访谈主界面。可以保留为**可选**的悬浮组件（60%透明度），但**不强制显示**。

如果保留思维气泡，要求：
- ✅ 默认60%透明度，鼠标悬停时变为80%
- ✅ 独立悬浮于右侧，不占用主界面空间
- ✅ 可关闭/最小化

如果不保留，也符合本次简化的核心要求。

## 🔴 必须删除的模块清单

### 模块1：题目过渡参考（❌ 全部删除）

**当前状态**：
显示2条过渡脚本，例如：
- "从能力判断转向日常感知"
- "探索受访者的AI意识"

**删除原因**：
- 违背"访谈者自主掌控节奏"原则
- 过渡脚本是开发者的内部参考资料，不应展示给访谈者
- 占用界面空间，分散注意力

**删除指令**：

```jsx
// ❌ 删除整个 TransitionReference 组件

// 文件位置（可能的路径）：
// /src/components/TransitionReference.jsx
// /src/components/QuestionTransition.jsx

// 删除引用：
<TransitionReference ... />  // ❌ 删除这一行

// 删除组件文件：
// TransitionReference.jsx → 删除整个文件
```

```python
# ❌ 后端API不再返回过渡参考数据

@app.route('/api/interview/question')
def get_question():
    return {
        "question_id": "Q1",
        "content": "...",

        "transition_scripts": [...],
    }
```

### 模块2：追问建议（❌ 全部删除）

**当前状态**：
显示5条预设的追问问题，例如：
- "你是如何判断一个应用是否真正使用了AI的？"
- "在判断AI应用时，你有什么困惑吗？"
- "能举个具体的例子吗？"
- "你什么时候开始注意到AI的？"
- "有没有什么经历改变了你的看法？"

**删除原因**：
- 这是v2版本的"三步深入引导"的残留
- 违背v3_725"AI不知道现场应该问什么"的核心定位
- 固定问题会让访谈者变成"问题朗读者"
- 已被"四个思考窗口"中的"经验叙事"窗口取代

**删除指令**：

```jsx

### 模块3：访谈记录大文本框（❌ 全部删除）

**当前状态**：

- 与"被访者回答"输入框功能重复
- 大文本框鼓励"逐字记录"，违背"深度倾听"的访谈原则

```

### 模块4：访谈旅程地图（可选，建议简化）

**当前状态**：
左侧显示完整的5阶段+15题的旅程地图。

**处理方案**（二选一）：

**方案A：完全删除（推荐）**
- 理由：占用左侧空间，分散注意力
- 替代方案：在顶部显示极简进度条
  ```
  阶段1: 认识AI | Q1/2  ▓▓░░░░░░░░░░░░
  ```

**方案B：简化保留**
- 只在顶部显示当前阶段和题号
- 不显示完整的15题列表
- 用户无法点击跳转（避免打断访谈流程）

**推荐方案A**，因为更符合极简原则。

### 模块5：用户类型信息（可选，建议极简化）

**当前状态**：
右侧显示用户的类型标签（摸鱼人、爱探索、信任AI、重功能）。

**处理方案**（二选一）：

**方案A：完全删除（推荐）**
- 理由：访谈过程中不需要持续提醒用户"你是什么类型"
- 类型信息已在结果页展示，访谈界面无需重复

**方案B：极简化保留**
- 只在右上角显示一个小图标（如"🐱 ETF"）
- 不展开任何文字说明
- 鼠标悬停时显示tooltip

**推荐方案A**，因为访谈者不需要在访谈时关注自己的类型。

## 📐 重构后的完整组件结构

```jsx
// components/SimplifiedInterviewPage.jsx
// 重构后的极简访谈界面

import React, { useState } from 'react';
import QuestionDisplay from './QuestionDisplay';
import AnswerSelector from './AnswerSelector';
import ThinkingWindows from './ThinkingWindows';
import WindowContent from './WindowContent';
import NavigationButtons from './NavigationButtons';
// ❌ 不再import：TransitionReference, FollowUpSuggestions, InterviewRecord

const SimplifiedInterviewPage = ({
  question,
  answer,
  onAnswerChange,
  onPrevious,
  onNext,
  currentStage,
  stageName,
  questionNumber,
  totalInStage
}) => {
  const [activeWindow, setActiveWindow] = useState(null);

  const handleToggleWindow = (windowType) => {
    setActiveWindow(activeWindow === windowType ? null : windowType);
  };

  return (
    <div className="simplified-interview-page">

      {/* 顶部极简进度条 */}
      <div className="stage-progress-bar">
        阶段{currentStage}: {stageName} | Q{questionNumber}/{totalIn_stage}
      </div>

      {/* 主内容区：三要素 */}
      <div className="main-content">

        {/* 要素1：当前题目 */}
        <QuestionDisplay
          question={question}
          currentStage={currentStage}
          stageName={stageName}
          questionNumber={questionNumber}
          totalInStage={totalInStage}
        />

        {/* 要素2：答案选择器 */}
        <div className="answer-section">
          <label>你的答案：</label>
          <AnswerSelector
            value={answer}
            onChange={onAnswerChange}
          />
        </div>

        {/* 要素3：四个思考窗口 */}
        <ThinkingWindows
          activeWindow={activeWindow}
          onToggle={handleToggleWindow}
        />

        {activeWindow && (
          <WindowContent
            windowType={activeWindow}
            content={question.思考窗口[activeWindow]}
            answer={answer}
            onClose={() => setActiveWindow(null)}
          />
        )}

        {/* 导航按钮 */}
        <NavigationButtons
          onPrevious={onPrevious}
          onNext={onNext}
        />

      </div>

      {/* ❌ 不再渲染以下组件：
        - TransitionReference
        - FollowUpSuggestions
        - InterviewRecord
        - InterviewJourneyMap (左侧)
        - UserInfoPanel (右侧)
      */}

    </div>
  );
};

export default SimplifiedInterviewPage;
```
